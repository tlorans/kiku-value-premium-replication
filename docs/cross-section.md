# Cross-sectional properties of prices and returns

The cross-sectional object is a pair of claims that differ only in cash-flow loadings. Average returns on that pair are not used to choose the loadings. The investor and the consumption process stay those of the replica.

Value is the first pair. The later sorts ask whether the same IMRS still accounts for cross-sectional properties of prices and returns when the characteristic is no longer book-to-market.

| Pair | Characteristic | Loadings | Page |
|:---|:---|:---|:---|
| Value, growth | Book-to-market | $$(\mu,\phi,\varphi,\alpha)$$ | [Value]({% link value.md %}) |
| Size, profitability, investment | Fama and French (2015) | same four | [Section 6]({% link further.md %}) |
| Transition, physical | Carbon and location | $$(\mu,\phi,\Omega^i,\Gamma^i)$$ | [Section 7]({% link climate.md %}) |

A sort that differs only in $$\phi$$ is the value mechanism under another name. The [time-series]({% link time-series.md %}) object is the market claim, not these pairs.
