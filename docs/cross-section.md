# Cross-sectional properties of prices and returns

The time-series object is the market claim. The cross-sectional object is a pair of claims that differ only in cash-flow loadings. Average returns on that pair are not used to choose the loadings.

Value is the first pair, and the argument of the paper. The later sorts keep the same investor.

| Pair | Characteristic | Loadings | Page |
|:---|:---|:---|:---|
| Value, growth | Book-to-market | $$(\mu,\phi,\varphi,\alpha)$$ | [Sections 2–5]({% link implications.md %}) |
| Size, profitability, investment | FF2015 | same four | [Section 6]({% link further.md %}) |
| Transition, physical | Carbon and location | $$(\mu,\phi,\Omega^i,\Gamma^i)$$ | [Section 7]({% link climate.md %}) |

A sort that differs only in $$\phi$$ is the value mechanism under another name. [Other portfolios]({% link generalization.md %}) is the same map written as a recipe.
