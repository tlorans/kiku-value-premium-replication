# The replica

Sections 2–5 are the paper. Cash-flow dynamics are calibrated to consumption and dividends. The Euler equation is then asked to account for both time-series and cross-sectional properties of assets’ prices and returns.

| Section | Object |
|:---|:---|
| [2. Empirical evidence]({% link empirical.md %}) | Value, growth, and the market, 1930–2003 |
| [3. The long-run risks model]({% link model.md %}) | IMRS and heterogeneous $$\phi$$ |
| [4. Calibration]({% link calibration.md %}) | Cash-flow moments only |
| [5. Asset pricing implications]({% link implications.md %}) | Market row: time series. Value–growth rows: cross section |

The six-percent premium is a fact in Section 2. It is not an input to Section 4. If it appears in Section 5, it is a prediction.
