# Value

Value is the first cross-sectional pair, and the argument of the paper. Growth and value have market betas near one. They do not have the same loading $$\phi$$ on $$x_t$$. An Epstein–Zin investor prices that difference. The Euler equation then requires a higher expected return on value and a lower price–dividend ratio.

The six-percent premium is a fact in [Section 2]({% link empirical.md %}). It is not an input to [Section 4]({% link calibration.md %}). [Section 5]({% link implications.md %}) reads the premium and the valuation ranking off the Euler equation. Model value premium about 5.3 percent against about 6 percent in the data. Mean $$\log(P/D)$$ 3.10 on value against 3.65 on growth.

$$(\mu,\phi,\varphi,\alpha)$$ are estimated from consumption and dividends. Average returns do not enter. $$\phi_V=6.2$$ against $$\phi_G=2.6$$. $$\mu$$ is higher on value as well; $$\phi$$ wins the valuation ranking.

The later pairs keep this investor. They change the characteristic.
